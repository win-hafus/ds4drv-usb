======================================
USB Emulation для Bluetooth DualShock 4
======================================

Причина, почему эта штука существует
=====================================

Некоторые игры (например, Detroit: Become Human) на Linux не работают с DualShock 4, подключенным через Bluetooth, но корректно работают с USB-подключением.

Добавлена опция ``--force-usb-emulation``, которая заставляет ds4drv создавать виртуальный контроллер с параметрами USB DualShock 4, даже если физический контроллер подключен через Bluetooth.

Использование
=============

Командная строка
----------------

.. code-block:: bash

    ds4drv --hidraw --force-usb-emulation


Конфигурационный файл
---------------------

Добавьте в ``~/.config/ds4drv.conf``:

.. code-block:: ini

    [ds4drv]
    hidraw = true
    force-usb-emulation = true


Технические детали
==================

При использовании ``--force-usb-emulation``:

- Виртуальное устройство создается с ``bustype = BUS_USB``
- Используется vendor ID: 1356 (Sony)
- Используется product ID: 1476 (DualShock 4)
- Имя устройства: "Sony Computer Entertainment Wireless Controller"

Это идентично тому, как система видит настоящий USB DualShock 4.

Примечание
==========

Физическое устройство остается подключенным через Bluetooth. Изменяется только то, как виртуальный контроллер представляется системе и играм.
